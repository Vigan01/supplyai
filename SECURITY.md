# Security Policy

## Supported versions

SupplyAI is in early development. Security fixes are applied to the default branch until the first stable release exists.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities. Contact the repository owner privately and include:

- Affected version or commit
- Reproduction steps
- Impact assessment
- Any known workaround

The project owner should acknowledge the report, validate the issue, and publish a fix before sharing technical details publicly.
